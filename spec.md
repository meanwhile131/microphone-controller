## Введение
Приложение с графическим интерфейсом для ПК на Windows или Linux, которое принимает звук гитары (или подобного музыкального инструмента, настроенного на 12-тональную музыку где A4 = 440 Гц и каждая следующая нота имеет частоту в $\sqrt[12]{2} \approxeq 1.06$ раз больше предыдущей) и нажимает клавишы клавиатуры, заданные пользователем для каждой ноты (частоты).

## Назначение продукта
Эмулировать нажатие клавиш клавиатуры соответственно нотам гитары (или подобного музыкального инструмента).

## Требования к ПО
Должно:
- На протяжении своей работы считывать звук с микрофона (или line in) и анализировать его в (почти) реальном времени.
- Выделить играемые ноты/нажимаемые клавишы в текущий момент времени в графическом интерфейсе.
- Дать возможность пользователю настроить чувствительность (громкость, при которой будет нажиматься соответствующая ноте клавиша).
- Дать возможность пользователю настроить клавишу, соответствующую ноте/частоте из таблицы нот.
- Отображать график звучащих частот в реальном времени.
- Автоматически сохранять (при каждом изменении параметров) настройки между перезапусками (QSettings).
- При выборе ячейки и нажатии:
    - клавишы: задавать клавишу для ноты
    - Esc: сбрасывать ноту (отвязывать от клавишы)

Дополнительный функционал:
- Выбор пользователем используемого микрофона (диалог или QComboBox).
- Кнопка сброса всех настроек
