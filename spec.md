## Введение
Приложение с графическим интерфейсом для ПК на Windows или Linux, которое принимает звук гитары (или подобного музыкального инструмента, настроенного на 12-тональную музыку где A4 = 440 Гц и каждая следущая нота имеет частоту в $\sqrt[12]{2} \approxeq 1.06$ раз больше предыдущей).

## Назначение продукта
Эмулировать нажатие клавиш клавиатуры соответственно нотам гитары (или подобного музыкального инструмента).

## Требования к ПО
Должно:
- Считывать звук с микрофона (или line in) и анализировать его в (почти) реальном времени.
- Нажимать клавишы клавиатуры, заданные пользователем для каждой ноты (частоты), при определенной (настраиваемой пользователем) громкости на этой частоте.
- Сохранять все настройки между перезапусками (QSettings)

## Этапы разработки
1. Анализ звука с микрофона (или line in)
2. Нажатие соответствующих клавиш на клавиатуре
4. Настраиваемый порог громкости
5. Сохранение настроек при перезапуске
6. Поддержка Windows
7. Выбор микрофона
8. Автонастройка порога громкости
