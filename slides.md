# Введение

Проект позволяет эмулировать нажатие клавиш клавиатуры ПК, играя ноты на музыкальном инструменте. Он был создал по желанию друга играть в Silksong используя гитару:

![Друг просит управление Silksong гитарой](https://github.com/user-attachments/assets/11c1c4f1-6379-4047-a161-d443266fac15)


---
# Реализация
Приложение написано на Python с PyQt6, также использует:
- `sounddevice` для считывания звука с микрофона
- `matplotlib` для графика частот
- `keyboard` для эмуляции нажатия клавиш

Для нахождения играемых частот используется быстрое преобразование Фурье из `numpy`

---
# Реализация
Функционал приложения разделен по файлам и классам:
- `main.py` создает интерфейс и загружает настройки
- `music.py` задает константы музыкальной теории
- `binding_handler.py` обрабатывает аудио и нажимает клавишы
- `fft_plot.py` рисует график частот
- `note_table.py` отображает играемые частоты и привязанные кнопки в таблице
