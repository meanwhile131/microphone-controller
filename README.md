## Как использовать
1. Скачайте [последний релиз](https://github.com/meanwhile131/microphone-controller/releases/latest)
2. Подключите музыкальный инструмент или микрофон к Line In или разъему микрофона
3. Запустите (с root-правами если на Linux)
4. Сверху слева выберете устройство ввода
4. Настройте чувствительность (левый слайдер/красная линия — порог нажатия, правый слайдер/зеленая линия — порог отпускания)
5. Выберите ячейку и нажмите клавишу клавиатуры (повторите для всех нот/клавиш), при обнаружении этой частоты будет эмулироваться нажатие клавишы.
6. Смените фокус на другое окно
7. Играйте ноты чтобы нажимать клавиши
